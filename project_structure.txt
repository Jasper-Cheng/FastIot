# 技术栈:
# - FastAPI: Web框架
# - SQLAlchemy: ORM框架
# - Pydantic: 数据验证
# - MQTT: 物联网通信
# - WebSocket: 实时通信
# - Redis: 缓存和消息队列
# - Docker: 容器化部署
# - Poetry: 依赖管理

# 权限控制状态:
# - 已移除所有基于角色的访问控制 (RBAC)
# - 已移除所有权限制检查
# - 所有认证用户均可访问所有端点
# - 仅保留基本的资源存在性验证

# 主要功能模块:
# 1. 用户管理: 账号、用户、成员、管理员
# 2. 设备管理: 设备、设备型号、设备网络、设备日志、设备参数
# 3. 房间管理: 房间、房间设备关联
# 4. 告警管理: 告警、告警统计
# 5. 权限管理: 成员设备权限（已简化）
# 6. 物模型管理: 物模型、设备型号
# 7. 实时通信: WebSocket、MQTT
# 8. 数据存储: MySQL、Redis
