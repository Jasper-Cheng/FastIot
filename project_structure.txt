# 技术栈
# - FastAPI, Uvicorn
# - SQLAlchemy 2 (async + aiomysql)
# - Pydantic / pydantic-settings
# - MQTT (gmqtt), WebSocket
# - Docker Compose
# - Poetry

# 部署说明
# - .env 为 Docker 环境变量（mysql 服务名，MQTT 用 host.docker.internal）
# - 宿主机映射端口：MYSQL_HOST_PORT=3307 等见 .env
# - 构建时 .dockerignore 排除 .env，运行时由 compose 注入

# 主要功能
# - 账号/家庭/成员、设备/物模型/型号、签到/积分、反馈、系统消息、版本
# - 客户端认证（RSA+密码）、管理端认证
# - MQTT 设备数据与状态实时推送
